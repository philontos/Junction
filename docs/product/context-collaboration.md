# Context 与协作：首期功能草案

1. **保存 Context**：将 Claude Code、Codex 的会话保存为独立的上下文。
2. **查看内容**：浏览对话、工具结果和附件，查看来源。
3. **保存版本**：保存当前进展，保留历史版本供后续使用。
4. **跨 Agent 接续**：选择已有 Context，交给 Claude Code 或 Codex 继续工作。
5. **租户隔离**：各租户拥有独立空间，Context 默认私有。
6. **选择分享**：选择 Context 的版本、内容和附件，分享给指定租户。
7. **接收共享**：查看其他租户分享的 Context，按需引用。
8. **独立开展工作**：基于共享 Context 继续工作，形成自己的 Context，并保留来源关联。
9. **撤销共享**：取消指定租户的访问权限，停止后续访问。
10. **提示缺失**：明确提示缺失或无法使用的内容。
