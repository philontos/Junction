# Context 与协作：v0.1

1. 导入 Claude Code、Codex 的现有 JSONL；原文件只读，重复上传去重。
2. 同时保存原件和标准化历史，记录来源、解析版本与缺失提示。
3. 保存不可变版本，分页查询对话、轮次和工具详情，完整导出。
4. 用户独立持有 Context；未分享的记录保持私有。
5. 一键分享固定版本，同一 Junction 的用户可读取；原件保留作底稿。
6. 从共享列表选择 Context，取消分享后停止后续公共读取。
7. 通过 CLI 和 skill 读取前情；Switchyard 可新建本机任务、选择 Agent 继续工作。
8. 支持本地启动、凭证轮换、完整性检查和备份恢复。

暂不做：公开匿名分享、用户分组、派生关系、多人编辑、实时同步、原生运行态恢复、代码/worktree 搬运、附件复制或 Agent 托管。

本版验收先覆盖服务和 CLI；真实任务的 Claude Code ↔ Codex 双向交接在本地联调阶段完成。
